Unit 7

There is / There are

يوجد / توجد · النفي · الأسئلة · some و any

There is · There are · There isn't · There aren't · Is there? · Are there? · some / any

🗺️ Visual Summary — لمحة بصرية سريعة

الخلاصة الكاملة للدرس — يوجد · لا يوجد · هل يوجد؟

There is → مفرد · There are → جمع · isn't / aren't للنفي · Is/Are there? للسؤال

➕ There is / There are — الإيجاب

نستخدم there is مع المفرد — وthere are مع الجمع

Singular — مفرد There IS + a/an + noun مفرد معدود
Uncountable — غير معدود There IS + some + noun ماء · حليب · خبز
Plural — جمع There ARE + some + noun-s جمع معدود
💡 there is يُختصر إلى there's — أما there are لا يُختصر في الكتابة الرسمية
Examples — أمثلة
There is a sofa in the living room.
يوجد أريكة في غرفة الجلوس.
There is an oven in the kitchen.
يوجد فرن في المطبخ.
There is some milk in the fridge.
يوجد بعض الحليب في الثلاجة.
There are three bedrooms in the flat.
يوجد ثلاث غرف نوم في الشقة.
There are some chairs around the table.
توجد بعض الكراسي حول الطاولة.
There's a park near our house.
يوجد حديقة قريبة من بيتنا. (there's = there is)

❌ There isn't / There aren't — النفي

للنفي نضيف not — مع مفرد: isn't — مع جمع: aren't — ونستخدم a/an أو any

Singular — مفرد There ISN'T + a/an + noun = There is not
Plural — جمع There AREN'T + any + noun-s = There are not
Uncountable — غير معدود There ISN'T + any + noun ماء · خبز · وقت
⚠️ في النفي نستخدم any وليس some — There aren't any chairs. ✅ · There aren't some chairs. ❌
Examples — أمثلة
There isn't a lift in the building.
لا يوجد مصعد في المبنى.
There isn't any water in the bottle.
لا يوجد ماء في الزجاجة.
There aren't any windows in this room.
لا توجد نوافذ في هذه الغرفة.
There aren't any eggs in the fridge.
لا توجد بيض في الثلاجة.
There isn't a garden in this flat.
لا توجد حديقة في هذه الشقة.

❓ Is there? / Are there? — الأسئلة

للسؤال نعكس الترتيب — is/are تأتي قبل there — والجواب المختصر: Yes, there is / No, there isn't

Singular question IS there + a/an + noun? مفرد
Plural question ARE there + any + noun-s? جمع
Short Answers — الأجوبة المختصرة
السؤالنعملا
Is there a kitchen?Yes, there is.No, there isn't.
Are there any shops?Yes, there are.No, there aren't.
Examples — أمثلة
Is there a swimming pool in the hotel?
هل يوجد مسبح في الفندق؟
Yes, there is. It's on the roof.
نعم، يوجد. إنه على السطح.
Are there any supermarkets near here?
هل توجد أي سوبرماركت قريبة من هنا؟
No, there aren't. But there's a small shop.
لا، لا توجد. لكن يوجد متجر صغير.
Is there any bread left?
هل يوجد أي خبز متبقٍّ؟
WH Questions — أسئلة WH
How many rooms are there in the flat?
كم غرفة يوجد في الشقة؟
What is there in the kitchen?
ماذا يوجد في المطبخ؟
Where is there a hospital?
أين يوجد مستشفى؟

📦 some / any — بعض / أي

some للإيجاب — any للنفي والأسئلة — مع الجمع المعدود والغير المعدود

some ✅ إيجاب
There are some apples. / There is some milk.
any ❌ نفي
There aren't any apples. / There isn't any milk.
any ❓ سؤال
Are there any apples? / Is there any milk?
💡 استثناء: نستخدم some في الأسئلة عند العرض أو الطلب — Would you like some tea? / Can I have some water?
Examples with food — أمثلة بالطعام
There are some oranges in the bowl.
توجد بعض البرتقال في الوعاء.
There isn't any coffee left.
لا يوجد قهوة متبقية.
Are there any eggs in the fridge?
هل توجد أي بيض في الثلاجة؟
There is some bread on the table.
يوجد بعض الخبز على الطاولة.
Would you like some water?
هل تريد بعض الماء؟ (عرض → some في السؤال)

جمل حقيقية تصف الأماكن والغرف — استمع وكرر

يوجد شرفة.

توجد متاجر كثيرة.

There isn't any sugar.
لا يوجد سكر.

Is there a gym?
هل يوجد صالة رياضية؟
On a street 🛣️
Are there any taxis?
هل توجد سيارات أجرة؟

There are 30 students.
يوجد 30 طالباً.
Describing a room — وصف غرفة
In my bedroom, there is a bed and a wardrobe. There are two windows and some shelves on the wall.
في غرفتي، يوجد سرير وخزانة ملابس. وتوجد نافذتان وبعض الرفوف على الجدار.
In the kitchen, there is a fridge and a microwave. There isn't a dishwasher.
في المطبخ يوجد ثلاجة وميكروويف. لا توجد غسالة صحون.

⚠️ Common Mistakes — أخطاء شائعة

أكثر الأخطاء التي يقع فيها الطلاب

There are a chair in the room.
There is a chair in the room.
a chair مفرد → نستخدم is وليس are
There is some chairs.
There are some chairs.
chairs جمع → نستخدم are وليس is
There aren't some books.
There aren't any books.
في النفي نستخدم any وليس some
Is there any chairs?
Are there any chairs?
chairs جمع → السؤال يبدأ بـ Are there
There is a milk in the fridge.
There is some milk in the fridge.
milk غير معدود → لا نستخدم a/an معه

📚 My New Flat — Sara's Story
📍 PlaceLondon, UK
👤 PersonSara — new tenant
🏠 TopicDescribing a flat
📖 Grammar focusthere is · there are · there isn't · there aren't

My name is Sara and I have a new flat in London. There are three rooms in the flat — a bedroom, a living room, and a small study. There is also a kitchen and a bathroom.

The living room is my favourite room. There is a big comfortable sofa and there are some colourful cushions on it. There is a large window, and there are some plants near the window. There is a soft carpet on the floor and there is a lamp in the corner.

The kitchen is small but it has everything I need. There is a fridge, a microwave, and a small oven. There are three cupboards on the wall. There isn't a dishwasher, so I wash the dishes by hand. There isn't much space, but it is perfect for one person.

In the bedroom, there is a comfortable bed and a big wardrobe. There are some shelves on the wall for my books. There aren't any curtains yet — I need to buy some!

The building is in a great location. There is a supermarket just across the street, and there are some good restaurants nearby. There is a bus stop at the corner. There isn't a car park, but that is fine because I don't have a car.

I am very happy with my new flat. There are some things I still need to buy, but it already feels like home!

15Common Mistakeاختيار
✅ There is a car park outside.
car park مفرد → there is — خطأ شائع: استخدام are مع المفرد
16some / anyأملأ الفراغ
Is there _______ water in the bottle?
💡 تلميح: في الأسئلة العادية نستخدم any
✅ Is there any water in the bottle?
في الأسئلة العادية نستخدم any — (some فقط في العرض والطلب)
17there isn't / aren'tاختيار
✅ There isn't any sugar in the cupboard.
sugar غير معدود → there isn't وليس there aren't
📦
some / any — القاعدة الكاملة
some ✅ إيجاب + عرض
There are some apples.
There is some milk.
Would you like some tea?
Can I have some water?
any ❌❓ نفي + سؤال
There aren't any apples.
There isn't any milk.
Are there any shops?
Is there any water?
8 أسئلة متبقية فقط — أنت قريب جداً! ركّز وأنهِ بقوة
18there is + uncountableاختيار
✅ There is some bread on the table.
bread غير معدود → there is (دائماً مفرد مع الغير معدود)
19Questionأملأ الفراغ
_______ a swimming pool in the hotel?
💡 تلميح: swimming pool مفرد → السؤال: Is there?
✅ Is there a swimming pool in the hotel?
مفرد → Is there + a/an + noun?
20Common Mistakeاختيار
✅ Are there any chairs in the office?
chairs جمع → السؤال يبدأ بـ Are there — خطأ شائع: Is there مع الجمع
21there's contractionاختيار
✅ There's a bus stop at the corner.
there's = there is (اختصار المفرد فقط) — there're غير مستخدم رسمياً
22Negative + anyأملأ الفراغ
There _______ any curtains in the bedroom.
💡 تلميح: curtains جمع + نفي → aren't
✅ There aren't any curtains in the bedroom.
curtains جمع → النفي: there aren't + any
23How manyاختيار
✅ How many rooms are there in the flat?
rooms جمع → How many + noun + are there? وليس is there
24any in questionاختيار
✅ Are there any taxis outside?
في الأسئلة العادية نستخدم any مع الجمع وليس some
25Full sentenceاختيار
✅ There is some furniture in the room.
furniture غير معدود (لا يُجمع) → there is دائماً وليس there are
